Markdown Viewer 代码逻辑与实现说明
生成时间：2026-07-29

一、项目定位

Markdown Viewer 是一个不使用 Electron 的 Windows 本地 Markdown 桌面查看器。
主程序使用 Python + Tkinter 实现，目标是提供：

1. Markdown 文件打开、源码查看、预览查看、分屏查看。
2. DeepSeek API 翻译，支持选中文本翻译和全文翻译。
3. 右侧译文栏，支持 Markdown 样式渲染和原文/译文双向滚动同步。
4. Windows 当前用户文件关联，支持 .md、.markdown、.mdown、.mkd。
5. 自定义图标、完整安装向导、快捷方式、卸载项。

项目目录：
E:\CUBE18\markdown viewer

主程序：
E:\CUBE18\markdown viewer\markdown_viewer.pyw

安装向导：
E:\CUBE18\markdown viewer\installer\installer_ui.py

最终安装包：
E:\CUBE18\markdown viewer\release\MarkdownViewerSetup.exe


二、主要文件结构

1. markdown_viewer.pyw
   主应用程序。包含 Tkinter UI、Markdown 渲染、DeepSeek 翻译、设置保存、滚动同步、文件打开等核心逻辑。

2. installer\installer_ui.py
   完整安装向导。使用 Tkinter 编写安装界面，负责解压程序载荷、创建快捷方式、写注册表、写卸载项。

3. installer\app-payload.zip
   安装器内嵌载荷。由 dist\MarkdownViewer 目录压缩生成，包含独立运行版主程序和 Python/Tk 运行时文件。

4. assets\markdown-viewer.ico
   应用图标，同时用于 exe 图标、窗口图标、文件关联图标。

5. register-file-association.ps1 / unregister-file-association.ps1
   源码版文件关联脚本。注意：安装版文件关联由 installer_ui.py 写入，指向独立 exe。

6. launch.cmd
   源码版启动脚本，查找 pyw.exe / pythonw.exe / python.exe 运行 markdown_viewer.pyw。

7. release\MarkdownViewerSetup.exe
   当前发布用安装程序，带完整安装路径和安装选项 UI。

8. 工作日志.txt
   迭代记录与验证结果。

9. 归档_临时文件和回滚_20260729\
   集中存放临时构建产物、旧版安装器文件和重要修改前的回滚备份。

七、Markdown 打开与预览逻辑

文件打开流程：

choose_file()
-> filedialog.askopenfilename()
-> open_path(filename)
-> 尝试 utf-8-sig 读取，失败后使用 gb18030 容错读取
-> load_markdown(markdown, path)
-> 写入 source_text
-> render_preview()
-> update_header()

源码编辑流程：

source_text 绑定 <<Modified>>
-> on_source_modified()
-> after(350) 防抖
-> sync_source_to_preview()
-> 更新 current_markdown
-> render_preview()

预览渲染：

render_preview()
-> render_markdown_into(preview_text, current_markdown)
-> 更新 toc_targets
-> update_search()

Markdown 渲染不是完整 Markdown 引擎，而是基于 Text tag 的轻量渲染器：

1. 支持标题 # / ## / ###
2. 支持粗体、斜体、行内代码
3. 支持代码块 ```
4. 支持引用 >
5. 支持列表 -、*、+、数字列表
6. 支持水平分割线
7. 表格目前按等宽代码样式显示

核心函数：
- configure_markdown_tags(text)
- render_markdown_into(text_widget, markdown)
- _insert_plain(text_widget, value, tags)
- _insert_inline(text_widget, value, base_tags)

十、滚动同步逻辑

目标：
原文/预览滚动时译文跟随，译文滚动时当前原文视图也跟随。

涉及控件：
- source_text
- preview_text
- translation_text

滚动入口：
1. yscrollcommand 回调
2. 鼠标滚轮事件
3. OverlayScrollbar 拖动

核心函数：
- on_source_yview()
- on_preview_yview()
- on_translation_yview()
- on_text_mousewheel()
- schedule_scroll_sync()
- run_scroll_sync()
- sync_translation_to_widget()
- sync_active_content_to_widget()
- sync_texts_by_visible_line()

同步策略：

不是直接用 yview 百分比同步，而是使用“顶部可见逻辑行”计算：

1. source.index("@0,0") 获取源 Text 当前顶部可见行。
2. source.index("end-1c") 获取源总行数。
3. 计算当前位置比例。
4. 用比例换算目标 Text 的目标行。
5. target.yview("目标行.0")。

这样比简单 yview_moveto(first) 更适合原文和译文行高、段落间距不同的情况。

为了减少卡顿：

1. schedule_scroll_sync() 使用 after_idle 合并高频回调。
2. resize 期间设置 _resizing_layout，暂停同步。
3. resize 结束后 finish_window_resize() 再对齐一次。


十一、DeepSeek 翻译逻辑

配置项：

1. API Key
   用户在“设置 > DeepSeek API 配置”中填写。

2. 模型
   - deepseek-v4-flash
   - deepseek-v4-pro

3. Base URL
   固定为 https://api.deepseek.com

4. 翻译质量模式
   - 快速翻译
   - 精翻

设置保存：

load_settings()
save_settings()

配置文件路径：
%APPDATA%\MarkdownViewer\settings.json

API Key 使用 Windows DPAPI：

protect_secret(value)
unprotect_secret(value)

Windows 下调用 CryptProtectData / CryptUnprotectData，加密后再 base64 存入 settings.json。

翻译入口：

1. translate_selection()
   获取 preview_text/source_text 当前选中文字。

2. translate_document()
   翻译 current_markdown 全文。

3. translate_current_scope()
   根据 translation_scope_var 选择 selection 或 document。

翻译主流程：

start_translation(text, source_label)
-> 检查 API Key
-> 获取目标语言、模型、质量模式
-> split_translation_chunks(text)
-> show_translation_progress(total)
-> 禁用翻译按钮
-> 后台线程 translation_worker()

后台线程：

translation_worker()
-> translate_online()
-> 成功后 after(0, finish_translation_success)
-> 失败后 after(0, finish_translation_error)

分段并发：

translate_online()
如果只有一个 chunk，直接 translate_chunk()。
如果多个 chunk：
1. deepseek-v4-flash 最大并发 12
2. deepseek-v4-pro 最大并发 4
3. 使用 ThreadPoolExecutor 并发请求
4. 按原 index 放回 translated_chunks，保证顺序不乱
5. 每完成一段调用 update_translation_progress()

请求体：

POST https://api.deepseek.com/chat/completions

headers:
Authorization: Bearer {api_key}
Content-Type: application/json
User-Agent: MarkdownViewer/1.0

payload:
model: deepseek-v4-flash 或 deepseek-v4-pro
messages:
  system: 根据快速/精翻模式选择 system prompt
  user: 要求翻译为目标语言，并保留 Markdown 结构
thinking:
  快速翻译：{"type": "disabled"}
  精翻：{"type": "enabled"}
temperature:
  快速翻译：0.1
  精翻：不设置

译文处理：

finish_translation_success()
-> set_translation_text()
-> render_markdown_into(translation_text, translated)
-> fade_translation_result()
-> complete_translation_progress()

因此译文栏不是纯文本显示，而是复用 Markdown 渲染器按标题、粗体、代码等样式渲染。


十二、进度与状态反馈

翻译进度：

show_translation_progress(total)
如果 total <= 1：
使用 indeterminate Progressbar，文字为“翻译中...”

如果 total > 1：
使用 determinate Progressbar，文字为“正在翻译 第 done/total 段”

完成：
complete_translation_progress()
-> Progressbar 切换 Success 样式
-> 显示“翻译完成”
-> 1.5 秒后 hide_translation_progress()

错误：
finish_translation_error()
-> 译文栏显示“翻译失败：{错误内容}”
-> 状态栏提示检查网络
-> 隐藏进度条
-> 恢复按钮

HTTPError 会读取 API 返回正文，方便定位 400 Bad Request 等问题。

十八、已实现的关键优化

1. UI 顶部工具栏收纳
   原常驻按钮和搜索框已收进菜单和搜索弹窗，主内容区更干净。

2. 翻译栏隐藏修复
   使用 PanedWindow forget/add 直接隐藏和恢复，不再依赖 sash 动画。

3. Markdown 译文渲染
   译文使用 render_markdown_into()，和正文预览共用 Text tag 渲染。

4. 双向滚动同步
   使用顶部可见逻辑行同步，解决译文滚动不带动原文、原文滚动不同步的问题。

5. 浮动滚动条
   OverlayScrollbar 默认隐藏，鼠标靠近文本区右侧或滚动时显示。

6. 高 DPI 支持
   启动时设置 DPI awareness，减少字体模糊。

7. DeepSeek API 错误可见
   HTTPError 会展示响应正文，方便定位 400 等错误。

8. 完整安装向导
   setup 有安装路径选择和完整流程 UI。

1. Markdown 渲染
   当前是轻量 Text tag 渲染，不是 CommonMark 完整实现。
   如果需要更完整支持表格、图片、链接点击、任务列表，可考虑引入 markdown-it-py 或 mistune 解析 AST，再映射到 Text tag。

2. 滚动同步
   当前基于可见逻辑行比例同步。
   如果需要更精准的段落对齐，可在原文和译文分段时建立段落 anchor 映射。

3. 翻译分段
   当前按字符长度和换行分段。
   如果需要更稳定保持 Markdown 结构，可按标题/段落/代码块边界切 chunk。

4. API 模型
   模型 id 当前按用户要求固定为 deepseek-v4-flash 和 deepseek-v4-pro。
   如果 DeepSeek 官方模型名变化，需要同步更新 DEEPSEEK_MODELS 和 MODEL_DISPLAY。

5. 安装器
   当前安装器写 HKCU，不需要管理员权限。
   如果未来要全用户安装到 Program Files，需要增加管理员权限 manifest 和 HKLM 注册逻辑。

6. 代码拆分
   当前主程序为单文件，方便交付。
   如果继续扩展，建议拆成：
   - app.py / main.py
   - ui/widgets.py
   - ui/layout.py
   - markdown_render.py
   - translation.py
   - settings.py
   - windows_integration.py

7. 测试
   目前主要靠 py_compile、Tk smoke test、安装器静默安装验证。
   如果继续长期维护，建议增加 pytest 单元测试：
   - settings 加解密
   - DeepSeek payload 构造
   - Markdown 渲染 tag
   - chunk 分段
   - 安装器路径安全逻辑
